# 弹臂卡扣式散热片安装结构（虚构）

## 背景

电子设备发热器件需加装散热片。常见方案用螺丝或导热胶固定，拆装慢、板面占孔多。希望一种**免工具、可重复拆装**的安装结构。

## 方案要点（形状 / 构造）

1. **散热基板**：平板，下表面贴发热器件，上表面一体或固定**竖直鳍片阵列**。  
2. **弹性卡扣臂**：自基板两侧向下延伸，末端设**向内钩部**。  
3. **电路板缘**：对应位置开设缺口或凸台，钩部咬合后限位，并可手压弹臂解除。  
4. **对称布置**：左右各至少一臂，防止装反（防呆）。

## 与「方法类发明」的边界

本案保护的是**零件形状与连接关系**，不是散热控制算法或贴装工艺步骤。若创新在温控策略，应改走发明。
